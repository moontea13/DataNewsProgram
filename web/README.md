# 换一部，还是这一个？

中文 AI 短剧数据新闻网页。以 2026 年 7—10 月红果月榜为线索，从封面、故事结构、生产来源、榜单换新走到观众评论。

## 运行与构建

需要 Node.js 和 Python 3，无需安装 npm 依赖。在 `web/` 目录执行：

```bash
npm run dev
# http://127.0.0.1:5173

npm run build
# 生成 dist/；双击 dist/index.html 即可离线阅读

npm run preview
# 在本地 HTTP 服务中检查 dist/
```

部署时上传整个 `dist/` 目录。构建包含运行数据、本地封面、D3 与 Scrollama，不依赖同伴服务器或外部字体服务。中文字体使用本机宋体和黑体。

## 页面与交互

- 五组相似封面看板，共 17 个系列。固定采用 DINOv2 中心裁剪特征、0.70 展示阈值；每组所有封面两两达标，再逐图核对构图、标题排版和色彩。组内封面可打开作品详情，完整 169 张封面收进阅览室。
- 同一组故事随阅读依次展开核心冲突、关键转机、应对路径；同一系列接着展开续季、同出品署名与原著线索。观察维度横向滑动，作品保留在原处。
- 换新数量先用柱形图分层讲述，再在同一坐标系中逐条加入作品、系列、结构簇折线。最后的月份标线与头尾榜位窗口自动轮换，无需逐月点击。
- 柱形图与封面随进入视野展开。月份轮换在悬停、聚焦、读详情或离开页面时停留，并提供暂停按钮；系统开启减少动态效果时默认暂停。
- 使用暖纸底色、淡玫瑰/灰绿/浅米黄章节背景和有厚度的封面。顶部是小型浮动章节入口，数据方法集中在文末。

## 数据

全篇使用 400 条榜位、368 部分季作品、196 个系列；结构分析纳入 180 个系列、85 个全局结构簇。封面、剧名及早期词项实验使用 169 个固定代表系列，其中 OCR 有效 162 个。评论包含 3,260 条原始热评、3,049 条有效热评、27 条明确跨系列相似反馈。

图表使用交付材料中的实际统计。五组封面是展示案例，其 0.70 阈值不替换原实验主分析，也不用于推断全样本同质化比例。风格补充实验修正后的排除关联结果优先于旧交付结果。各图保留自己的分母，书目候选与已确认改编分开标注。

运行与构建只需要已提交的 `public/`。`npm run data` 是可选的全量再生成步骤，需要本地 `临时/解包/part123`、`临时/解包/style` 及 `web/source-data/part45.json`。这些原始交付材料不进入 Git；公共仓库保留生成后的网页数据与必要缩略图。

## 开源来源

复用 [Scrollytelling Kit](https://github.com/anriueno/scrollytelling-kit) 的 D3 图表工厂、主题工具和完整步骤状态控制；本地修改了导入路径、中文提示及零值方格图处理，并保留 MIT 许可证与上游代码快照。D3 版本为 7.9.0，Scrollama 为 3.2.0。

视觉参考 [Pudding 封面作品](https://pudding.cool/2023/10/romance-covers/)、[The Price of a Year](https://price-of-a-year.vercel.app/) 和 [Kevin Bacon](https://pudding.cool/2026/10/kevin-bacon/)。没有引入第二套前端运行时或专有字体。
