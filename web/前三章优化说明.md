# 前三章展示优化

本版在main网页的纸张、封面书页与章节配色上修改，工作分支为`codex/first-three-editorial`。

- 治理背景独立为报道引入，保留发布日、准确原文、来源及与样本的时间关系。
- 封面完整展示五组彩色案例及可切换的标题区域框线，再展示全样本三种口径。图像候选展示阈值按用户要求设为0.50，148/169系列（87.6%）；原0.85结果留在展开的方法说明中作为对照。
- 剧名用颜色拆分固定句式与可变内容，删去重复的角落注释；具体模板覆盖仍为27/169。
- 故事直接展示三个不同系列的完整简介与九处可精确定位的高亮，随后展示共同结构与总体统计。
- 结构主样本采用联合包146系列/74组；档案成员与主统计一致。原词项、月份和热力图放入补充统计，AIGC探索说明移至方法。
- 来源先展示四个月的额外榜位，再追踪作品与出品署名；来源关系用实线/虚线、明确分类、证据节选及链接区分。
- 删除重复图注、模板标签、来源展柜的重复页脚；保留文字用正常字号呈现。导航和整体题名没有重做。

## 运行

无需安装npm依赖。Node.js运行开发服务：

```sh
npm run dev
```

构建：`npm run build`。需Python 3；Windows可先设置环境变量`PYTHON`为解释器的完整路径。构建目录`dist/index.html`可直接双击打开，或用`node scripts/serve.mjs --dist --port 8788`查看。

数据与模板检查：

```sh
node scripts/check_editorial.mjs
```

`public/data/editorial.json`冻结了修订后的结构成员、统计与证据，页面正常运行不依赖外部联合包。需要重新同步时，运行：

```sh
python scripts/prepare_editorial.py --delivery /path/to/红果数据新闻_联合交付版
```

源文件相对路径与SHA-256记录在`editorial.json`。同步不重跑模型；页面展示阈值在editorial.js中选择已有实验结果，数据文件保留全部已计算阈值。

## 范围

本次编辑只针对引入、前三章及对应方法说明。第四、五章和结尾保留原分支快照，其结构、换新与评论统计尚未切换到联合包，不应拿来与前三章主分析直接合并。发布整篇报道前仍需另行统一这些章节的统计范围。
