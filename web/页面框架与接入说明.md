# 页面框架与接入说明

## 整篇叙事

**封面画廊引入 → 第一眼的相似 → 故事配方 → 生产来源 → 榜单换新 → 观众回声 → 结尾与方法。**

核心沿用 Scrollytelling Kit 的滚动控制与图表工厂。Pudding 风格用于有厚度的封面、分组看板和作品探索；全篇使用同一套中文字体、暖纸底色与低饱和章节配色。顶部仅保留浮动的小型章节入口。

## 连续展示

- **封面**：五行看板，每行 3—4 张相近封面，共 17 个系列。固定使用 DINOv2 中心裁剪、0.70 阈值，组内任意两张均达标；编辑核对外观后选择展示组。完整画廊折叠保留，不提供模型或阈值选择器。
- **故事**：同一结构簇的作品持续显示，下方依次滑入题材、核心冲突、关键转机、应对路径及共同结构。可换组、核对原文。
- **来源**：保留同一系列封面，依次展开分季作品纸页、同出品署名的其他系列、原著与作者。纸页代表季作品，不捏造单季封面；书目候选保留候选标签。
- **折线**：作品、系列、结构簇按阅读步骤逐条加入同一坐标系，最后自动轮换四个月的标线与当月数字。上方柱形图提供对应的分层说明。
- **集中度**：7—10 月头部、尾部榜位窗口自动横向轮换，可比较榜位计数与系列去重两种口径。

三个连续场景在 `src/exhibits.js`，支持滚动、视角按钮、左右方向键和移动端轻扫。月份窗口在视野内推进，悬停或聚焦停留，详情打开及页面隐藏时暂停；减少动态效果时默认暂停。柱形图与封面进入视野时展开。

## 数据来源与版本

本地材料包括 `临时/红果新闻网页_Part1-3_交付包.zip`、`临时/红果风格补充实验_交付包.zip`，以及同伴第 4、5 部分 `http://123.56.64.232:8088/data.js` 的 `2026-11-13-final-v1.0` 快照。

网页只读取 `public/data/` 中已生成的数据，封面缩略图位于 `public/assets/covers/`，运行时不访问同伴服务器。`public/data/provenance.json` 保留交付版本与计数口径；补充实验的关联排除后结果优先于旧统计。展示组元数据与全部组内配对分数见 `cover_groups.json`。

GitHub 提交只包含网页源码、必要的运行数据、缩略图与许可证；`临时/`、原始 ZIP、`web/source-data/`、构建目录和缓存均排除。

## 后续维护

- **改文字**：全文在 `src/main.js`，连续场景文字在 `src/exhibits.js`，柱形图与评论的滚动说明在 `src/story.js`。
- **改样式**：基础样式在 `src/style.css`，连续场景在 `src/exhibits.css`，看板和动画在 `src/reader.css`。
- **换统计**：修改 `public/data/` 对应文件；结构改变时同步修改渲染函数，然后运行 `npm run build`。
- **更新交付包**：保留同样的本地解包目录，明确选择新版快照后运行 `npm run data`，再构建。只构建无需原始交付包。
- **调整封面组**：编辑 `scripts/prepare_cover_groups.py`，用原配对表逐对校验后生成 `cover_groups.json`。不要只验证参照封面与其他成员。
- **新增步骤**：定义每一步完整状态，确保向前与反向阅读结果一致。月份自动轮换由 `src/motion.js` 统一控制。
- **静态发布**：在 `web/` 运行 `npm run build`，上传完整 `dist/`。源码推送 GitHub 不会覆盖同伴服务器。
