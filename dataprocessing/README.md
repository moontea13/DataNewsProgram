# 数据爬取与处理

本目录为项目的 `dataprocessing/` 模块。以下命令均在本目录内执行；克隆代码后先在项目根目录解压独立数据包，再运行脚本。

当前范围：2026年7—10月。双平台800条榜单记录，红果400条已全部核图，抖音暂缓补采。红果400条均有简介封面候选，3260条公开热评关联394条上榜记录；版本、主体及AI制作仍按证据分级。

## 常用入口

| 要找什么 | 位置 |
| --- | --- |
| 按剧名、月份筛选全部记录 | [上榜记录总索引](data/交付索引/上榜记录总索引.csv) |
| 简介、封面和原始页面路径 | [素材明细](data/交付索引/素材路径明细.csv) |
| 同系列、各季、重复上榜 | [系列导航](data/交付索引/红果系列导航.md) |
| 评论正文 | [评论主表](data/红果400条交付/评论全覆盖/评论主表.csv) |
| 还缺什么、哪些分析没做 | [缺口明细](data/交付索引/缺口明细.csv) · [数据说明与待办](资料/数据说明与待办.md) |
| 出品方、原著和作者证据 | [关系核实说明](data/红果400条交付/关系核实/说明.md) |
| OCR核查与修正记录 | [核查说明](data/红果400条交付/OCR核查_20261112/说明.md) |

可筛选的Excel清单：[采集交付清单.xlsx](outputs/采集交付清单.xlsx)。包含总览、上榜索引、红果作品、素材明细、缺口明细和关系对应六张表。Excel为导出时快照，完整简介保留在素材CSV与按月导航中。

## 目录分工

```text
项目根目录
├── scripts/                       全部采集、处理、核查脚本，平放
├── data/
│   ├── 红果400条交付/             当前红果数据：简介封面、系列、评论、关系
│   ├── 交付索引/                  筛选表、按月导航、缺口与路径核验
│   ├── raw/                       原始榜图和网页证据
│   ├── ocr/                       榜图识别文本框
│   ├── 作品匹配/                  双平台匹配及AI证据
│   ├── 补采/                      补采原页与中间表
│   ├── 红果简介封面/              简介处理输入与历史材料
│   └── 公开评论/                  早期试采批次，不与新评论重复计数
├── outputs/                       可筛选Excel清单
└── 资料/                          合并后的数据说明、待办与整理记录
```

所有脚本说明见 [scripts/README.md](scripts/README.md)。日常离线重建运行 `bash scripts/重建数据.sh`，只刷新索引运行 `python3 scripts/生成交付索引.py`。

用户方案和Word留在上级项目根目录并保持原样，不纳入代码仓库；旧说明、旧脚本路径与新目录的对应关系见[数据说明](资料/数据说明与待办.md)。原始证据与核查记录保留，缓存和过期处理备份已清理。

当前仍有353条抖音OCR待核、6条红果评论入口/页面待补、5条红果原页缺失、1条同名版本待定。核查与分析的不同缺口可以落在同一记录上，不相加当作品数。

最近索引核验：800条主键唯一，红果400条均连接作品、系列和候选素材，12166次路径检查中实际来源引用/哈希异常0次。详情见[校验结果](data/交付索引/校验结果.json)。
