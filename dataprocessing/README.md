# 数据爬取与处理

本目录保存当前交付数据，后续直接用于分析。2026年11月13日已完成人工核对与旧目录清理，旧采集、补采和重建流程停用。

## 目录分工

```text
dataprocessing/
├── data/
│   ├── 红果400条交付/  当前简介封面、系列、评论、关系与人工核查记录
│   ├── 交付索引/       筛选表、按月导航及缺口与核对记录
│   ├── raw/            原始榜图、作品及评论网页证据
│   ├── ocr/            榜图识别文本框
│   ├── 作品匹配/       基础映射与平台系列材料
│   └── 补采/           保留的来源页面、候选版本及关系证据
└── outputs/            可筛选Excel清单
```

旧脚本保留在代码目录供查阅。旧流程输入目录已清理，后续使用当前交付表；本次不运行旧重建或索引生成命令。

研究范围统一为2026年7—10月红果月榜。原始证据与核查记录保留，当前表格和导航为日常阅读入口。

当前仍有6条红果评论入口/页面待补、5条红果原页缺失、1条同名版本待定。核查与分析的不同缺口可以落在同一记录上，不相加当作品数。

本轮核对与清理结果见[清理记录](../数据梳理/待核实事项与文件夹清理.md)。系列分组与季号标注已由负责人核对，平台编号缺失和未标季保留现有值；出品方、原著及历史身份未取得补充证据的继续留待查。
