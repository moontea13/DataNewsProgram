# 统计结果预览页

本页用于浏览第4、5部分定稿统计，标明“结果预览 · 非最终作品”。纯静态页面，无外部字体、脚本和运行时依赖。

## 文件

- `dist/index.html`：网页入口，可直接双击打开。
- `dist/style.css`、`dist/app.js`：样式与交互。
- `dist/data.js`、`dist/data.json`：由定稿结果生成的展示数据。
- `dist/统计结果CSV.zip`：六张定稿统计表。
- `qa/数据构建核对.json`：数据来源哈希与关键数量核对。

## 更新数据

在课程项目根目录运行：

```powershell
python ymc45/code/build_preview.py
```

## 服务器部署

将 `dist` 内全部文件放到独立的静态站点目录，使用 Nginx 等静态服务器提供访问。页面资源均采用相对路径，支持通过服务器 IP 的端口或子路径打开。无需安装 Node.js 或 Python 到服务器。
