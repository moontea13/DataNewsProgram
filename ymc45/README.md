# 第4、5部分：统计结果

版本：2026-11-13-final-v1.0。样本包含400个榜位、368部作品和196个系列；180个系列归入85个结构簇，另有16个系列因材料不足排除结构统计。

## 从这里开始

- [统计方法与结果说明](统计方法与结果说明.md)：四项指标、统计口径、主要结果和排除情况。
- [定稿结果](results/reviewed/)：指标统计表、结构簇、系列标注、评论与明细数据。
- [编码手册](编码手册.md)：结构与评论的分类规则。
- [网页预览](result-preview/dist/index.html)：浏览图表、结构簇和评论案例；这是结果预览页。

## 文件目录

| 目录 | 内容 |
|---|---|
| `results/reviewed/` | 定稿统计、标注结果及可视化数据 |
| `result-preview/` | 预览网页及部署配置 |
| `annotations/` | 标注依据、补充材料和决策数据 |
| `review/` | 用户补充判断原文，供部分结果引用 |
| `code/` | 统计和网页数据生成代码 |

CSV 文件采用 UTF-8 BOM 编码，列表等复杂字段使用 JSON 字符串。网页展示数据可以在课程目录运行 `python ymc45/code/build_preview.py` 重新生成。

为便于阅读，已移除旧候选结果、校审表和过程日志；依赖这些材料的原全流程复算脚本不再适用。定稿统计表、标注依据和代码保留。
