## 项目背景

### 概述

该项目是《新闻安全分析》的结课课程设计作业，要求最终交付一个数据新闻作品。我们组做的主题是探究AI短剧的同质化现象，题目暂定为：AI 短剧，究竟有多少不同的故事？

### 最终成果：

做一个动画丰富美观优雅前端网页，利用各式各样的图表格式/图像等等生动形象地展示我们统计的各项数据以及对应的分析。

### 灵感来源

[国家广播电视总局 工作动态 国家广播电视总局部署开展新一轮微短剧专项治理工作](https://www.nrta.gov.cn/art/2026/11/6/art_114_74410.html)

《国家广播电视总局部署开展新一轮微短剧专项治理工作》中提到要部署开展新一轮微短剧低俗化同质化专项治理工作。抓到了关键词“同质化”

## 我负责的任务

主要负责"D:\武大24级网安2班\课程\大三上\新闻安全分析\AI短剧同质化数据新闻方案.md"中4、5部分的数据处理清洗、标注、统计与分析。

统计四个指标：

指标1：每个月首次出现的作品、系列、结构簇的数量

指标2：新出现的系列沿用此前结构的情况

指标3：评论中对跨系列相似的反馈

指标4：重复对象与评价态度



## 数据范围

统一使用2026年7—10月红果月榜，每月100条，共400条上榜记录，全部作品已由项目负责人核实为AI短剧。原始来源的发布日期、评论发表时间和页面采集时间按原值保留。
