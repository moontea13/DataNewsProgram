# 封面与标题风格补充实验复现

从仓库根目录安装`requirements-models.txt`并准备完整数据后：

```bash
python run_pipeline.py base
python run_pipeline.py style
# 等价于 python run_pipeline.py all
```

输出默认为`outputs/style/`，可用`--style-output`指定。运行路径、其他参数与环境变量见[分析说明](README.md)。需要先有基础代表材料、原模型向量与基础封面；统一入口会保留依赖顺序。

## 方法与缓存

本轮在已阅读初轮结果后设计，是探索实验。`style_protocol.json`在提取前写入指纹锁，不能称为独立预注册。标题具体词典和模板另存于`results/style/title_codebook.json`。

沿用169个确认平台系列的固定代表版本，同系列续季和跨月重复不加权。两组已发现的人物/设定关联疑点登记在`identity_review.json`与协议中；基础分析也排除这两组。补充实验另按固定近名与简介低频双字片段条件筛查，不擅自把疑点合并为同一故事。当前样本14,196个候选配对中，14,194个允许配对。

DINOv2-small比较原中心裁切、完整图补边、OCR标题区域遮挡后补边。遮挡实验仅在OCR有效系列上解释，并提供同子集未遮挡对照；灰色遮挡不等于完美去字。Chinese CLIP固定commit为`36e679e65c2a2fead755ae21162091293ad37834`，比较官方完整图缩放与补边。OCR固定RapidOCR 1.4.4和ONNX Runtime 1.20.1，ONNX模型哈希写入元数据。

OCR缓存核验代表文件、协议、提取代码与单图SHA256；缓存失效会重新处理。新输出目录会补齐OCR叠图。风格向量绑定代表文件、协议、推理代码，DINOv2额外绑定OCR结果。旧版向量缺少这些元数据时应重新运行，不手动补写证明。修改规则后推荐用新的`--results`目录完整重跑。

## 使用边界

具体标题模板、粗粒度风格、语义相似分别输出。OCR框内颜色不等于字体颜色，框数不等于人工确认行数。共享布局组合不直接称为整图高度相似。

零样本人物数、景别、画风、构图允许未知；现有样本三个关键维度均非未知的仅1个系列，不能支撑可靠整体构图重复率。字体家族、描边和人物精确框未可靠取得，不用其他指标冒充。

各模型完整提供0.50—0.95每0.05一档的曲线，分数没有共同校准。500次题材×形态内置换只描述模板与词项内部关联，不推出因果或跨平台差异。所有结果需同时给分子、分母和方法。

两组疑点排除后，BGE-M3标题与简介在0.85下均为0/169。历史交付中的2.37%和1.18%属于旧口径；新代码与新输出优先。详细历史补充结果见[结果解读](../docs/风格补充实验结果.md)。
