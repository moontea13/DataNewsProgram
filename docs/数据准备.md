# 数据准备与成品交接

仓库只包含代码和方法文档。原始网页、榜图、封面、评论、模型权重及完整结果通过独立数据包交接，不从GitHub自动下载。

## 输入目录

默认解压后应有：

```text
dataprocessing/data/
├── 红果400条交付/
│   ├── 系列合并/
│   │   ├── 上榜记录_系列季映射.json
│   │   ├── 季作品表.json
│   │   └── 系列汇总.json
│   ├── 简介封面材料明细.json
│   ├── 关系核实/                 出品、原著与证据
│   └── …                        明细引用的封面与来源文件
├── 交付索引/上榜记录总索引.csv
├── 作品匹配/                    AI制作证据等
├── raw/                         原始来源、治理与受众引文
└── …                            数据包其他相互引用的材料
```

保留整个原数据包内部结构，不重命名封面/来源文件。上面的目录只是导航，不是只需这几个文件即可完整复现；`prepare`可预检主要入口，后续导出还会读取关系、背景证据和页面。路径引用及来源SHA256由验收核对。

数据放在仓库外时：

```bash
python run_pipeline.py all --source "../独立数据包/dataprocessing/data"
```

源目录只读。不要把输出设到数据目录内，也不要用已有网页交付JSON冒充原始输入。原始采集数据包含历史抖音和评论材料，保留是为来源与旧脚本兼容，当前分析仅使用红果Part 1—3所需部分。

## 分享什么

- 给重现实验的人：本代码仓库 + 独立源数据包；模型可自动下载，固定commit见下载脚本。
- 给新闻网页开发者：`outputs/part1-3/`与`outputs/style/`两个完整输出目录；保留`data/`、`assets/`、`tables/`、`preview/`与说明。
- 给策划和撰稿者：`docs/风格补充实验结果.md`、输出中的指标清单和来源；初轮报告只作研究过程参考。

浏览器查看请打开输出目录下的`preview/index.html`；代码里的`analysis/*preview*/`只是模板。不能仅发送一个HTML或把图片目录删除。
